System Manual

Everything you need to set up, operate, and maintain the trading knowledge base. This system uses AI to organize your trades, track strategy performance, and compound insights over time.

Claude Code / Cursor Plain text files
01

How It Works

The system is built on three folders and one schema file. You put raw material in. The AI organizes it into a structured wiki and tracks your strategy performance over time. Every session builds on the last.

raw/

Your input folder. Trade logs, chart screenshots, daily notes, research. Dump everything here — never organize it manually.

wiki/

AI-maintained knowledge base. Strategy files, setup patterns, lessons, master rulebook. You never edit this by hand.

outputs/

AI-generated reports, refinements, and analyses. Weekly summaries, health checks, strategy rankings all save here.

AGENTS.md

The schema file. Tells the AI what this knowledge base is, how to organize it, your risk parameters, and your prompt shortcuts.

The AI does not run automatically. It acts when you run a prompt. You trigger everything — the AI executes. Think of it as an analyst who does exactly what you ask, exactly when you ask.

ℹ

The AI reads AGENTS.md at the start of every session. Everything in that file — your trading focus, risk parameters, folder structure, and prompt shortcuts — is active from the moment you open the project.

08

Trade Log

Open raw/trades/TradeLog_KnowledgeBase.xlsx and log every trade immediately after exit. The Stats Dashboard tab updates automatically as you add rows.

!

Setup Name consistency is critical. Use the exact same name every time for each strategy. "Strategy 1" must always be exactly "Strategy 1" — never a variation. The AI groups all trades by this field. One inconsistent name breaks your entire stats history for that setup.

The following fields calculate automatically — do not type in them: Risk $, P&L $, R-Multiple, Win/Loss.

The Market Condition field must be one of four values exactly as written: Trending, Choppy, Volatile, Slow Grind. The monthly market condition analysis cross-references this field against your daily notes files — consistency here matters.

09

Daily Notes

Each trading day, duplicate YYYY-MM-DD-notes.md from raw/market-notes/, rename it to today's date (e.g. 2024-04-08-notes.md), and fill it in.

Pre-Market (2 min)

Mental state rating and one-sentence plan. Complete before 8:00am. If mental state is below 6, reduce size or sit out.

EOD Debrief (5 min)

Market condition, MNQ character, trades taken, rules followed, rules broken, what went well, what went wrong, one fix for tomorrow, day rating.

✓

Rate your execution, not your P&L. A day where you followed every rule and lost money is a 9. A day where you broke rules and made money is a 3. The rating tracks discipline, not outcomes.

10

Chart Screenshots

Screenshots are only useful if the AI understands what it is looking at. Every screenshot needs a companion row in raw/charts/ChartScreenshotNotes.xlsx.

ℹ

Naming convention: YYYY-MM-DD-MNQ-setup-name-OUTCOME.png
Example: 2024-04-08-MNQ-mean-reversion-WIN.png
Multiple trades same day: 2024-04-08-MNQ-mean-reversion-0923-WIN.png

Screenshot wins, losses, and skips. Correctly avoided setups are some of the most valuable training data in the system — they teach the AI what your disqualifiers look like in practice. Label outcome as SKIP for those.

In the companion note, describe exactly what you saw — volume characteristics, candle structure, context. Do not rely on the image alone. The AI learns from your description, not just the visual.

16

Managing Strategies

Every strategy moves through a defined lifecycle. Status changes must be logged in the strategy's Rule Change Log.

StatusPosition SizeCriteria
🟡 TESTING 25–50% normal risk New or unproven. Rules may still be evolving. No conclusions until 20+ trades.
🟢 ACTIVE Full normal risk 20+ trades logged, positive expectancy, rules fully written and trusted.
🔴 PAUSED Zero Conditions shifted or 3+ consecutive losing weeks. Edge may still exist.
⚫ RETIRED Zero — permanent 30–40 trades with no positive expectancy. File kept for reference, never traded again.

To promote a strategy from TESTING to ACTIVE, run the Promote prompt from wiki/PROMPTS.md. The AI verifies the 20-trade threshold and positive expectancy before updating the status. To retire a strategy, run the Retire prompt — the AI adds a Retirement Summary before archiving.

To add a new strategy, duplicate wiki/strategies/strategy1.md, rename it, fill in your rules, and add a row to wiki/strategies/INDEX.md manually. Then update the Strategies list in AGENTS.md.

17

Rule Changes

Rules change based on data, not feelings. Every change must be logged. The Rule Change Log in each strategy file is the permanent record of what changed and why.

!

Never change a rule based on fewer than 5 data points. One bad trade is not a pattern. Wait until you have evidence. The monthly rule audit flags rules that need revisiting based on sufficient data.

1

Identify the rule

Which specific rule in the strategy file is at issue? Be precise — "exit rules" is not specific enough.

2

Pull the data

How many trades are affected? Run !deep [strategy name] to get the AI's analysis before deciding anything.

3

Make the decision

You decide whether to change the rule. The AI recommends — you decide.

4

Update the wiki

Run the Rule Change prompt from Section 15. AI updates the strategy file and logs the change with today's date.

5

Update AGENTS.md if needed

If the change affects how the AI should evaluate future trades system-wide, update AGENTS.md accordingly.

18

Health Checks

Run !health on the last trading day of every month without exception. This is your quality control. The monthly health check does four things:

Validation Check

Flags any strategy with fewer than 20 trades as ⚠️ UNVALIDATED. You cannot trust conclusions from a small sample.

Contradiction Check

Finds wiki articles that say conflicting things. Happens when rules change but old content is not updated.

Source Check

Lists claims in wiki/ not backed by actual trade data in raw/. Catches AI errors before they compound.

Gap Identification

Suggests 3 specific things to research or track next month based on what the knowledge base is missing.

⚠

If the AI writes something slightly wrong and you save it back without checking, the next analysis builds on that error. The monthly health check is the only mechanism that catches this. Do not skip it.

19

Compounding Loop

The system compounds because every answer saved back to the knowledge base becomes context for the next question. The loop is explicit — it only works if you close it deliberately.

1

Add raw material

Trades, screenshots, daily notes. Anything that belongs in raw/.

2

Run !daily

AI reads new content, updates wiki, recalculates stats. Closes the day.

3

Ask a question

Run any analysis prompt. AI answers using the full wiki as its knowledge source.

4

Save the answer back

Run the Save Answer prompt. AI writes to outputs/ and updates wiki/ with the new insight.

5

Next question is smarter

The wiki now contains that insight. Future analyses build on it. Repeat.

✓

The system is only as good as the discipline behind it. Consistent daily logging and prompt execution for 60–90 days produces a personalized, data-backed playbook that no course or book can replicate — because it is built entirely from your own trades.
